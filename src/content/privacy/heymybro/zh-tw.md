## 1. 我們是誰

「欸! 粗哥」（以下稱「本 App」，Android 套件名稱 `com.dongyutech.heymybro`）是一款朋友之間的分帳與記帳應用程式。

|            |                        |
| ---------- | ---------------------- |
| 資料控管者 | 動域科技股份有限公司   |
| 聯絡信箱   | contact@dongyu.company |

本政策說明本 App 蒐集哪些資料、為什麼蒐集、存在哪裡、誰看得到，以及你可以怎麼處理這些資料。

## 2. 適用範圍

本政策適用於「欸! 粗哥」行動應用程式及其後端服務。本 App 內的「分享」功能會把內容交給你自己選擇的其他 App（例如 LINE、訊息、電子郵件）——內容一旦交出，就受該 App 自己的隱私權政策規範，不再由我們控制。

## 3. 我們蒐集哪些資料

### 3.1 你主動提供的資料

**建立帳號時（透過 Google 登入）**

- Google 帳號的 **電子郵件地址** 與 **使用者識別碼**，用於驗證你的身分並建立帳號
- Google 帳號的 **顯示名稱** 與 **大頭貼網址**，作為你個人檔案的初始值

我們透過 Google 的 ID Token 完成登入，**不會、也無法取得你的 Google 密碼**。

**個人檔案（部分為必填，部分可自由選擇是否填寫）**

| 欄位 | 必填？ | 說明 |
| --- | --- | --- |
| 使用者代號（handle） | 必填 | 3–20 個英數字或底線，全站唯一，是別人搜尋到你的唯一途徑 |
| 顯示名稱 | 必填 | 預設沿用 Google 名稱，可自行修改 |
| 大頭貼 | 選填 | 可沿用 Google 大頭貼或自行更換 |
| 性別 | 選填 | 男／女／其他／不願透露 |
| 生日 | 選填 | 儲存的是日期，不是年齡 |
| 自我介紹 | 選填 | 200 字以內 |

**使用本 App 時你輸入的內容**

- **揪團／群組**：名稱、封面顏色、成員名單
- **消費紀錄**：品項名稱、金額（新台幣整數）、誰先付的、每個人分攤多少
- **個人記帳**：品項名稱、金額
- **好友（bro）清單**：對方的帳號、你替他們設定的名稱
- **債務協商**：債務標題、金額、還款金額、以及你在拒絕時填寫的理由
- **結清紀錄**：誰付給誰、金額、時間

### 3.2 系統自動產生的資料

- **識別碼與時間戳記**：每一筆資料的 UUID、建立時間、更新時間、刪除時間
- **邀請碼與分享 token**：由伺服器以密碼學安全亂數產生，有到期時間（揪團邀請碼預設 7 天）
- **信用分**：由你在本 App 內的還款紀錄在**裝置上**即時計算而得，並非另行儲存的評分，也不會提供給任何徵信機構或第三方
- **App 設定**：主題模式、語言、主色，存在裝置本機

### 3.3 我們**不**蒐集的資料

- 精確位置或粗略位置
- 通訊錄或聯絡人清單
- 相簿或裝置檔案
- 付款資訊、信用卡號、銀行帳號
- 廣告識別碼（Advertising ID）
- 使用行為分析、事件追蹤、當機回報

本 App **沒有整合任何分析、廣告或當機回報 SDK**。

## 4. 你的資料存在哪裡

本 App 的資料分成兩層：

### 4.1 你的裝置上（本機資料庫）

以下資料以 SQLite 資料庫儲存在你的手機內：揪團、成員、消費與分帳明細、個人記帳、好友清單（含對方名稱、代號與大頭貼網址的快取）、結清紀錄、債務協商紀錄，以及 App 設定與方案狀態。

在 Android 上，本 App 明確關閉了系統備份（`allowBackup=false`），因此這個包含財務紀錄的資料庫**不會被 Android 自動備份或 `adb backup` 取出**。

### 4.2 我們的伺服器上（Supabase）

需要跨裝置、跨使用者同步的資料（帳號、個人檔案、共享的揪團與消費、好友關係、債務協商）會儲存於我們代管的 Supabase（PostgreSQL）資料庫。

|            |                                                          |
| ---------- | -------------------------------------------------------- |
| 服務商     | Supabase Inc.                                            |
| 資料庫位置 | **日本東京（`ap-northeast-1`）**                         |
| 傳輸加密   | 所有連線一律使用 HTTPS / TLS                             |
| 存取控管   | 每一張資料表都啟用資料列層級安全性（Row Level Security） |

## 5. 誰看得到你的資料

這是分帳 App 最重要的一節。我們在資料庫層級（而不只是在 App 介面上）強制執行以下規則：

**你的個人檔案（顯示名稱、大頭貼、性別、生日、自我介紹）只有三種人讀得到：**

1. **你自己**
2. **你的 bro**（雙方都已同意的好友關係）
3. **與你同一個揪團的成員**

除此之外的任何登入者都讀不到你的個人檔案。

**搜尋是刻意設計得很窄的。** 別人只能用**完全正確的使用者代號**找到你——我們不提供前綴搜尋，也不提供模糊比對，而且一次只回傳一筆結果，回傳欄位僅限代號、顯示名稱與大頭貼。這是為了防止有人靠著逐字嘗試把全站使用者名單掃出來。**你的性別、生日、自我介紹永遠不會出現在搜尋結果中。**

**共享揪團裡的內容，同團成員都看得到**：包含品項名稱、金額、誰付的錢、以及每個人分攤多少。請不要把不想讓同團成員看到的資訊寫進品項名稱。

**債務協商只有你和對方兩個人看得到**，包含金額、標題與拒絕理由。

**你的好友清單、個人記帳與備註是私人的**，即使是清單上的那位好友也看不到你怎麼稱呼他們、或你私下記了哪些帳。

**我們不會把你的資料販售、出租或分享給任何第三方做行銷用途。** 我們只會在下列情況揭露資料：法律強制要求、法院或主管機關的有效命令，或為了保護使用者人身安全的緊急必要。

## 9. 資料保留與刪除

**軟刪除與回收桶。** 當你刪除一筆揪團、消費、個人記帳或好友時，該筆資料會先移到 App 內的「回收桶」，你可以還原它。回收桶內的項目**不會自動過期**——它會一直留著，直到你自己按下永久刪除，或清空整個回收桶。永久刪除後，該筆資料會從你的裝置移除；已同步到伺服器的對應資料也會一併刪除。

**已結清的共享紀錄。** 為了維持帳目正確，一個已經產生結清紀錄的揪團無法再被編輯或刪除單筆消費——否則雙方的帳本會對不起來。你仍可以把整個揪團移到回收桶。

**帳號刪除。** 目前本 App 內尚未提供「刪除帳號」按鈕。若你希望刪除帳號及所有伺服器上的相關資料，請寄信至 **contact@dongyu.company**，我們會在收到請求後 **30 天內**完成刪除。刪除帳號會一併移除你的個人檔案、好友關係、債務協商紀錄，以及你所建立的揪團資料。

> 請注意：共享揪團中你參與過的消費紀錄，會同時存在於其他成員的帳本中。刪除你的帳號會移除你的個人身分資訊，但其他成員各自留存的分帳金額紀錄不會因此消失——那是他們自己的財務紀錄。

## 10. 你的權利

你隨時可以：

- **查看與更正**你的個人檔案（App 內的「帳號 → 編輯個人資料」）
- **刪除**你建立的任何紀錄（回收桶 → 永久刪除）
- **登出**，中斷本裝置與帳號的連結
- **要求匯出**你的資料副本，或**要求刪除**你的帳號——寄信至 contact@dongyu.company
- **撤回好友關係**，對方將立即失去讀取你個人檔案的權限

若你位於歐洲經濟區、英國或其他賦予類似權利的地區，你另有反對處理、限制處理及向當地資料保護主管機關申訴的權利。台灣使用者依《個人資料保護法》第 3 條享有查詢、閱覽、複製、補充更正、停止蒐集處理利用及刪除的權利。

我們會在收到請求後 **30 天內**回覆。

我們的伺服器位於**日本東京**。若你在其他國家使用本 App，你的資料會被傳輸到日本並在當地儲存與處理。使用本 App 即表示你了解並同意此項傳輸。

## 13. 資料安全

我們採取的具體措施包括：

- 所有網路連線一律使用 **HTTPS / TLS** 加密
- 資料庫每一張資料表皆啟用 **Row Level Security**，權限規則在資料庫層強制執行，而非僅依賴前端
- 邀請碼與分享 token 一律由**伺服器端以密碼學安全亂數產生**並設有到期時間
- Android 版停用系統備份，避免本機財務資料庫被外部工具取出
- 正式版建置移除偵錯用的日誌輸出
- 我們**從不儲存你的密碼**——身分驗證完全交由 Google 處理

沒有任何系統能保證絕對安全，但我們會持續維護上述防護。
